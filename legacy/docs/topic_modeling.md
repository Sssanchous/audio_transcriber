# Тематическое моделирование

По ТЗ тематическое моделирование нужно для группировки смысловых фрагментов по темам обсуждения: сроки, дизайн, оплата, сервер, ресурсы, риски.

В MVP используется rule-based fallback по ключевым словам. Если на следующем этапе подключить `BERTopic`, он сможет кластеризовать фрагменты транскрипции и уточнять темы автоматически.

Тяжёлая зависимость `bertopic` не добавлена в обязательные requirements, чтобы проект не ломался без ML-окружения.
