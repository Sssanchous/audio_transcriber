# Описание проекта

PM Insights анализирует русскоязычные проектные встречи по загруженным аудиофайлам. Цель MVP — подготовить устойчивую структуру, базовый pipeline и rule-based аналитику без тяжёлого развёртывания.

Система не записывает встречу и не использует микрофон. Источник данных — готовый аудиофайл пользователя или `.docx` протоколы в `transcripts` для формирования датасета.
