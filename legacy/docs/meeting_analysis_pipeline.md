# Pipeline анализа встречи

MVP pipeline:

1. проверить аудиофайл;
2. получить транскрипцию через ASR-интерфейс;
3. очистить русский текст;
4. разбить на фрагменты;
5. выделить задачи;
6. выделить вопросы и ответы;
7. выделить решения;
8. выделить дедлайны;
9. выделить ответственных;
10. выделить аспекты;
11. построить fallback topics;
12. посчитать тональность;
13. посчитать метрики;
14. сохранить JSON в `results`.
