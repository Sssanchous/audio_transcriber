# Обработка аудио

Пользователь загружает готовую аудиозапись встречи. Поддерживаются только `.mp3`, `.wav`, `.m4a`.

Перед выбором файла пользователь подтверждает правомерность загрузки и обработки. Drag&drop до подтверждения блокируется.

MVP использует ASR stub. Интерфейсы для Whisper и Vosk созданы, но реальные тяжёлые модели не подключаются автоматически.
