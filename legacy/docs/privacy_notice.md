# Конфиденциальность и правомерность обработки

PM Insights обрабатывает только аудиофайлы, которые пользователь самостоятельно загружает в систему.

Система не записывает встречи, не получает доступ к микрофону и не подключается к онлайн-конференциям. Пользователь должен иметь основания для загрузки и обработки аудиозаписи.
